# Itnry

Itnry is a browser-based itinerary preparer. Plan a trip by destination and dates, then fill each day with timed stops, places, and notes. Trips save automatically in local storage on this device.

## Features

- Create and manage multiple itineraries
- Auto-generate days from a date range
- Add, edit, reorder, and categorize stops
- Copy a plain-text summary or open a print / PDF view
- Local-only persistence (no account required)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
